# Arun Balaji M portfolio (Next.js)

    npm install
    npm run dev      # http://localhost:3000

Deploy: push to GitHub and import the repo in Vercel (no config needed).

## Fill in
- `public/resume.pdf` : your CV (the Download CV buttons point here)
- `public/images/projects/<slug>-desktop.png` and `<slug>-mobile.png` : screenshots for the preview toggle. Slugs: voice-assistant, outreach-bot, deprex. Until added, a placeholder is shown.
- `lib/data.js` : email, project links (repo), and any text you want to change
